# calculator-using-c
just a normal calculator that is built using c language.

LOGIC USED:
Switch: Different cases are used to detect the operation the user wants to perform.

CHALLENGING OPERAIONS:
1.When the user want the answer in decimal it takes the input as integer but later converts it to float so that the answer is precize.
2.When the user performs the division with 0 the ans is not defined , so the code says invalid "Error! Division by zero is not possible.".
